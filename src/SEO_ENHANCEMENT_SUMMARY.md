## 🚀 Advanced SEO Opportunities

### **1. Review/Rating Schema**
Add aggregate ratings to service pages:
```json
{
  "@type": "AggregateRating",
  "ratingValue": 4.9,
  "reviewCount": 127
}
```

### **2. Video Schema**
Add to portfolio items and blog posts with video:
```json
{
  "@type": "VideoObject",
  "name": "...",
  "description": "...",
  "thumbnailUrl": "...",
  "uploadDate": "..."
}
```

### **3. Local Business Schema**
If you have a physical office:
```json
{
  "@type": "LocalBusiness",
  "name": "CIELO Agency",
  "address": {...},
  "geo": {...},
  "openingHours": "..."
}
```

### **4. Event Schema**
For webinars, workshops, or events:
```json
{
  "@type": "Event",
  "name": "...",
  "startDate": "...",
  "location": {...}
}
```

### **5. Job Posting Schema**
Already have Jobs page - add schema:
```json
{
  "@type": "JobPosting",
  "title": "...",
  "description": "...",
  "datePosted": "..."
}
```
